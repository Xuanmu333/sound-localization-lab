# 听见位置 · 声源定位实验室

一个可离线运行的交互式 3D 实验：用四个同步麦克风的接收时间差，推算声音来自哪里。

![声源定位实验预览](docs/preview.png)

## 直接体验

下载仓库后，用现代浏览器打开根目录的 **index.html**。无需安装、服务器或联网。Three.js、字体和页面逻辑均已内嵌在单个 HTML 文件中。

- 拖动蓝色声源，或用坐标滑块移动。
- 切换「看声音传播」「比较时间差」「找到交点」三个观察层。
- 隐藏真实位置，再通过接收时间差定位。
- 支持随机位置、脉冲试听、立体 / 俯视切换、场景旋转与缩放。
- 自动导览会逐步展开三个观察层；操作页面即可接管。空闲 25 秒后恢复导览，系统启用减少动态效果时不自动启动。
- 布局适配桌面和手机。

## 原理与边界

每一组麦克风满足距离差关系：

```text
dᵢ − dₐ = c × (tᵢ − tₐ)
```

三组时间差对应三条位置约束曲线，定位程序通过最小化距离差残差求交点。反算函数仅接收时间差，不能访问声源真实坐标。空间动画、接收时刻、曲线和仪表读取同一套模型。

这是**理想二维模拟**，不是设备麦克风实测。模型假设声源与麦克风位于同一平面，声速为 343 m/s，麦克风位置已知且时钟同步，不考虑回声、噪声和采样误差。声源的操作范围位于麦克风阵列内部。视觉传播慢放 200 倍，接收波形为示意脉冲；试听播放原始发声脉冲，不模拟空间音频。

## 从源码构建

使用 Node.js 22 或更新版本：

```bash
npm ci
npm test
npm run build
```

构建会更新根目录 `index.html`。安装依赖需要网络；构建后的页面可离线运行。`package.json` 中的 `private: true` 仅防止误发布到 npm，不影响 GitHub 仓库公开访问。

## 文件结构

```text
src/model.mjs       声速、麦克风位置、观测模型、定位求解与等时间差曲线
src/main.js         3D 场景、交互、音频与自动导览
src/style.css       桌面与手机布局
scripts/build.mjs   单文件离线打包
tests/model.test.mjs  定位与曲线验证
index.html          可直接打开的完整演示
```

测试覆盖实验范围内 493 个位置、等到达时间的中心点、未知发声时刻，以及曲线与距离差的一致性。桌面与手机布局、拖动、隐藏声源、随机定位、视角、音频、导览和离线加载已在浏览器中检查。
